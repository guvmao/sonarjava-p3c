if语句嵌套不应超过3层。过深的嵌套会降低代码的可读性和可维护性。

错例：

    if (condition1) {
        if (condition2) {
            if (condition3) {
                if (condition4) {
                    doSomething();
                }
            }
        }
    }

正例：

    if (!condition1 || !condition2 || !condition3) {
        return;
    }
    doSomething();

建议使用卫语句、拆分方法或策略模式降低嵌套层数。
